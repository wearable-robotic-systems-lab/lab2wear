# Moticon SDK (not included)

The Moticon insole SDK (`moticon_insole3_service-03_05_00-release.aar`) is proprietary
software sold by Moticon and is not distributed in this repository.

To build the Moticon extension, obtain the SDK and license directly from Moticon
(https://moticon.com) and place the `.aar` file in this `libs/` folder. It is
referenced from `app/build.gradle.kts` and ignored by git.
